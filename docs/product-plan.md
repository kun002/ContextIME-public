# ContextIME 产品规划

## 1. 产品定义

ContextIME 是一款可安装、可分发、可配置的 Windows 开发者输入法。

必须满足：

- 安装后出现在 Windows 输入法列表；
- 独立完成拼音组合、候选显示、选词和上屏；
- 不依赖编辑器插件也能在普通 Windows 软件中输入；
- 针对代码、注释、终端、文档、AI 对话和项目术语优化；
- 每个用户都能配置自己的开发输入习惯；
- 本地学习，不上传源码和完整输入正文。

ContextIME 不是：

- VS Code 输入法切换插件；
- 微软拼音或微信输入法的控制器；
- 只适用于单个编辑器的辅助工具；
- 从零重写拼音算法和基础词库的项目。

## 2. 目标用户

核心用户：

- Windows 平台程序员；
- Unity、游戏开发和技术美术人员；
- 经常混合输入中文说明、英文标识符、路径、命令和技术术语的用户；
- 使用 VS Code、Visual Studio、JetBrains、Windows Terminal、Codex 等工具的用户。

核心问题：

1. 输入代码和中文说明时频繁切换中英文；
2. 中文输入中出现类名、方法名、路径和命令时被打断；
3. 普通输入法不理解代码、注释和项目上下文；
4. 项目专有名称难输入、候选排序不稳定；
5. 不同软件、输入区域和项目需要不同习惯；
6. 远程桌面和 Electron 软件中输入法状态容易混乱。

## 3. 核心能力

### 3.1 完整输入法能力

首个可用版本必须具备：

- 全拼；
- 拼音组合显示；
- 中文候选列表；
- 数字选词；
- 空格上屏；
- 候选翻页；
- 中英文切换；
- 中文/英文标点切换；
- 用户词频学习；
- 用户词典；
- 简体中文输出；
- Windows 注册、安装、升级和卸载。

基础能力优先复用 librime，不自行实现拼音分词、基础词库和候选排序。

### 3.2 开发者输入模式

默认规则：

| 场景 | 默认模式 |
|---|---|
| 代码 | 英文 |
| 注释 | 中文 |
| Markdown 正文 | 中文 |
| Markdown 代码块 | 英文 |
| 终端 | 英文 |
| 搜索框 | 英文 |
| Git 提交信息 | 中文 |
| AI 对话框 | 中文 |
| 字符串 | 用户配置 |
| 路径、URL、命令 | 英文 |
| 普通文档 | 中文 |

所有规则必须允许用户覆盖。

### 3.3 中英文混合输入

中文模式下应能连续输入：

```text
GameObject
PlayerController
Assets/Textures/UI
git status
https://github.com
Vector3.Lerp
```

需要支持：

- CamelCase、PascalCase、snake_case；
- 文件路径、URL、命令片段；
- 类名、方法名、变量名和技术术语候选；
- 英文片段结束后恢复原中文状态；
- 用户可以关闭任一自动规则。

### 3.4 项目词库

每个项目建立独立本地词库，可包含：

- 类名、方法名、属性名、枚举名和命名空间；
- 文件名、目录名、Unity 资源名和 Shader 名；
- 项目专有术语；
- 用户手动添加的词语。

约束：

- 默认只存符号和名称，不存完整源码；
- 不索引密码、Token、密钥和环境变量值；
- 用户可查看、删除、禁用项目词库；
- 大项目使用增量索引；
- 项目词库不能污染其他项目。

### 3.5 个人习惯

允许学习：

- 软件和输入区域默认模式；
- 注释、字符串、提交信息偏好；
- 常用中英文术语；
- 候选选择频率；
- 项目内词语频率。

必须提供：

- 查看、删除、清空学习记录；
- 暂停学习；
- 配置导入和导出；
- 隐私模式；
- 不记录完整输入正文。

## 4. 版本规划

### M0：路线重置

产物：

- 产品规划和技术路线；
- 固定 librime、Weasel 或替代 TSF 前端版本；
- 完成许可证审计；
- 当前 VSIX 标记为原型；
- 建立原生输入法主线目录和可重复构建说明。

验收：

- 新任务不再把 VSIX 当产品交付；
- 仓库明确区分原生输入法、共享核心、可选适配器和原型。

### M1：原生输入法基线

目标：ContextIME 出现在 Windows 输入法列表，并能正常完成拼音输入。

功能：

- 安装、注册、激活和卸载；
- 全拼、候选窗口、选词和上屏；
- 中英文状态；
- 用户词频；
- 基础设置入口。

验收：

- Windows 10、Windows 11 x64 可安装；
- 记事本、浏览器、VS Code、Visual Studio 和 Terminal 可输入；
- 连续输入 30 分钟无崩溃；
- 卸载后无残留注册；
- 服务异常不影响系统其他输入法。

M1 完成前，禁止继续开发编辑器专属高级功能。

### M2：开发者基础方案

功能：

- 开发者默认输入方案；
- 中文/英文标点配置；
- CamelCase、路径、URL、命令识别；
- 项目术语手动词典；
- 设置界面；
- 配置导入导出。

验收：

- 中文输入中可以连续输入常用类名、路径和命令；
- 英文片段结束后正确恢复中文；
- 无频繁模式抖动；
- 修改设置不需要重装输入法。

### M3：上下文服务

功能：

- 本地 Context Service；
- 版本化 IPC；
- 当前应用和输入区域识别；
- VS Code 可选适配器；
- 代码、注释、Markdown 上下文；
- 组合输入期间禁止自动策略变化。

验收：

- 无编辑器插件时输入法仍完整可用；
- 插件存在时提供精确上下文；
- 服务断开时退回普通开发者方案；
- 按键路径中无网络和长任务。

### M4：项目词库

功能：

- 项目识别；
- 符号增量索引；
- Unity、C#、TypeScript 项目词库；
- 项目切换、查看和删除；
- 候选来源标识。

验收：

- 新增符号可在合理时间内进入候选；
- 不上传和不保存完整源码；
- 大项目增量更新不阻塞输入；
- 项目关闭后不污染其他候选。

### M5：个人习惯

功能：

- 候选词频学习；
- 输入区域和项目偏好；
- 学习规则查看、删除和备份；
- 隐私模式。

验收：

- 用户明确纠正后，同场景三次内形成稳定偏好；
- 学习可以完全关闭；
- 学习数据中没有完整代码和敏感文本。

### M6：正式发布

功能：

- 签名安装程序；
- 自动升级和回滚；
- 崩溃日志；
- 隐私说明；
- 稳定版和测试版通道。

验收：

- 干净 Windows 环境安装、升级、卸载通过；
- 连续使用 8 小时无焦点丢失；
- RDP 基础测试通过；
- 不影响其他输入法。

## 5. 首版边界

首个公开测试版本只做：

- Windows x64；
- 简体中文全拼；
- 本地输入；
- 开发者默认方案；
- 基础混合输入；
- 项目词典；
- VS Code 可选增强；
- 本地配置和学习。

暂不做：

- macOS、Linux 和移动端；
- 云词库和账号系统；
- 跨设备同步；
- 语音、手写和 OCR；
- 大模型候选；
- 多人协作词库；
- 同时支持所有 IDE。

## 6. 核心验收指标

输入法基础：

- 按键响应不被上下文服务阻塞；
- 候选窗口打开延迟不可感知；
- 服务崩溃后仍能普通拼音输入；
- 候选组合期间禁止外部规则改变状态；
- 安装和卸载可重复执行。

开发场景：

- 代码/注释基础识别准确率不低于 98%；
- CamelCase、路径、URL、命令识别准确率不低于 95%；
- 单次焦点变化最多执行一次状态变化；
- 用户手动切换后短时间内不被自动规则覆盖；
- 项目词库不跨项目污染。

隐私：

- 不上传输入内容；
- 不保存密码、Token 和完整源码；
- 用户可查看并删除全部学习数据；
- 默认不包含网络能力。
